# مواصفة سبرايت-شيتات تيتو (TITO Spritesheet Spec)

> اترسم صفحة PNG واحدة لكل أنيميشن في القايمة دي. ابعتها لي وأنا أقصّها وأركبها
> في المحرك بنفس الأسماء — مفيش أي شغل مطلوب منك غير الرسم وترتيب الفريمات.

## 📐 قواعد فنية ثابتة (لأي صفحة)

| البند | القيمة |
|---|---|
| الصيغة | PNG-32 بخلفية **شفافة** (مش ماجنتا — الشفافية نفسها) |
| الاتجاه | الشخصية **باصة/بتحرك لاتجاه اليمين** — الفليب بيحصل في المحرك |
| الارتكاز | الرجلين على **نفس خط الأرض** في كل الفريمات، والخط ده هو حرفيا **أسفل الخلية** |
| التوسيط | جسم الشخصية في **نص عرض الخلية** (اللانج/اللكمة تخش جوه عرض الخلية) |
| مقاس الرسم | ارتفاع تيتو داخل الخلية: **384–512px** (داخل اللعبة بيكون 74px — التصغير بيظبط الحبر) |
| الخلية | كل فريمات الصفحة الواحدة **بنفس المقاس** (Grid منتظم — صف واحد أو أكتر، مش مهم) |
| التباعد | اترك 8px على الأقل بين الخلية والتانية |
| الظل | **ممنوع ظل مرسوم على الأرض** (المحرك بيعمله) |
| الستايل | حبري Neo-Noir زي البيئة: حدود سوداء عريضة + هاتشينج + تظليل كحلي-فحمي، لمعان بسيط |
| الهوية | هودي كحلي مفتوح + تيشيرت مخطط أبيض/أسود + جينز فاتح + لُفاف بوكس بيضا (مرجع: `assets2d/sprites/chars/tito_idle.png`) |
| السرعة | المقترح 12fps — الفريمات اللي مكتوب (hold) عندها بتمسك شوية |

## 🎯 أولوية لو هتشتغل على دفعات

1. **الدفعة الأولى (تشغيل أساسي):** idle, run, jump, fall, land, light1, light2, light3, heavy
2. **الدفعة التانية (حركة كاملة):** sprint, roll, slide, wallslide, climb, parry, pound
3. **الدفعة التالتة (ردود الأفعال):** hurt, stagger, dead + كل الـ fx

---

## تسليم

- حط الصفحات في مجلد: `assets2d/gen/chars_raw/` بالأسماء اللي فوق بالظبط.
- مش لازم تلتزم بعرض/طول موحد **بين** الصفحات — الموحّد إلزامي بس **جوه** نفس الصفحة.
- أول صفحة ابعتها وأنا هركبها وأرجعلك فيديو/صور تأكيد قبل ما تكمل الباقي.

## بعدين (الأعداء والبوس — نفس القواعد)

- `enforcer_*`: idle / walk / swing1 / swing2 / hurt / stagger / dead
- `sentry_*`: idle / walk / shield_bash / hurt / dead
- `marksman_*`: idle / aim / fire / reload / hurt / dead
- `raven_*`: idle / walk / cane_combo(×2) / rush / slam / reload_stance / hurt / reversal / dead
